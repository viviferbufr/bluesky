# ☁️ Blue Sky — Guia de Skincare

O **Blue Sky** é um site informativo desenvolvido com o objetivo de compartilhar conhecimentos sobre cuidados com a pele (*skincare*), apresentando dicas, orientações e conteúdos que ajudam os usuários a conhecer melhor sua pele e construir uma rotina de autocuidado.

O projeto busca proporcionar uma experiência simples, intuitiva e agradável, com uma identidade visual inspirada na leveza do céu e das nuvens.

## Funcionalidades

O site conta com diferentes páginas e conteúdos:

- **Início:** apresentação do projeto e acesso aos principais conteúdos.
- **Guia de Skincare:** informações sobre as etapas básicas de cuidados com a pele.
- **Tipos de Pele:** características dos diferentes tipos de pele.
- **Rotina Diária:** dicas e orientações para o autocuidado.
- **Texturas de Skincare:** apresentação das principais texturas de produtos.
- **Ingredientes:** informações sobre ingredientes utilizados em produtos de skincare.
- **Mitos e Verdades:** esclarecimento de dúvidas comuns sobre cuidados com a pele.
- **Dicionário da Pele:** consulta de termos relacionados ao universo do skincare.
- **Sobre Nós:** apresentação dos desenvolvedores e do projeto.
- **Contato:** formulário para envio de mensagens.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e responsividade.
- **JavaScript:** implementação de funcionalidades e interatividade.

## Identidade visual

A identidade visual do Blue Sky foi desenvolvida com tons de azul e branco, utilizando elementos inspirados em nuvens para transmitir leveza, tranquilidade e bem-estar.

O site também conta com adaptação para diferentes tamanhos de tela, proporcionando uma navegação mais acessível em computadores, tablets e celulares.

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Extraia os arquivos, caso tenha feito o download.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute o arquivo `index.html` no navegador.

```bash
git clone https://github.com/viviferbufr/Blue-Sky.git
```
